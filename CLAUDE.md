# Project notes
- This repo holds @tech_blogcorner short-form videos under `reels/`.
- **Before making any video, read `reels/_brand/STYLE_GUIDE.md` and follow it exactly.**
  The look comes from "7 Free AI Tools Every Student Needs". Don't change colors, fonts, font sizes, layout or the cover design.

## Script structure for EVERY video (owner's rule, 14 Nov: never skip)
Every video script follows these 6 beats, in this order (diagram: `reels/_brand/script-structure.jpg`):
1. **Pain** – open on the viewer's problem in frame 1, with the tool on screen and a gap they recognise
   from their own account (e.g. Shopify orders piling up, Google Ads at 0 conversions).
2. **Poke** – twist the knife: what the problem is costing them right now (money, leads, reach), so it hurts more.
3. **Fix** – the steps, one idea per scene.
4. **Payoff** – show the result after the fix, working (numbers moving, the green state). The high point.
5. **Recap** – a quick one-scene run-through of all the steps (checklist ticking through), so it's saveable.
6. **CTA** – one clear ask (send / save / comment KEYWORD), then Follow.
Before writing any voiceover, label each line with its beat. If a beat is missing, the script isn't done.
Details and pacing: `reels/PLAN.md`.

## Voiceover check before finalizing (owner's rule, 14 Nov)
Never finalize a voice without checking the script is read correctly.
1. Write the TTS text for the ear, not the screen: every number, time, price and percent spelled out the way a
   person says it ("a hundred and fifty", "two seconds", "four dollars ten", "seventy percent"), and abbreviations
   spelled as spoken ("C T A", "U G C", "P Max", "D I Y"). Keep digits only in on-screen text and captions.
2. Print the phonemes for every line (`k.tokenizer.phonemize`) and check each number, name and abbreviation.
3. Send the owner a short audio check of the lines with numbers or names, and get a yes before rendering.
4. Delivery must sound like an excited teacher, not a reader: short punchy lines, varied pace, emphasis words.
